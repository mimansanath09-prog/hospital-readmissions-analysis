\# 🏥 Hospital Readmissions Analysis — CMS HRRP Data



\## Project Overview



This project analyzes CMS Hospital Readmissions Reduction Program (HRRP) data to identify patterns in hospital readmission rates across states, medical conditions, and healthcare facilities.



The analysis focuses on understanding excess readmission ratios, Medicare penalty risk, and operational healthcare insights using Python and healthcare data analytics techniques.



\---



\## Business Problem



Hospitals with excess readmission ratios above 1.0 may face Medicare payment penalties under CMS HRRP guidelines.



This project identifies:

\- States with higher readmission trends

\- Conditions causing increased readmissions

\- Hospitals at higher penalty risk

\- Distribution of excess readmission ratios nationally

\## Key Analysis Performed



\### 1. State-wise Readmission Analysis

Identified states with the highest average excess readmission ratios.



\### 2. Condition-wise Analysis

Compared readmission rates across medical conditions.



\### 3. Distribution Analysis

Analyzed how hospitals perform relative to the CMS penalty threshold (1.0).



\### 4. Texas-specific Healthcare Insights

Performed regional analysis focused on Texas hospitals.



\### 5. Hospital Performance Benchmarking

Identified top best and worst performing hospitals based on excess readmission ratio.
